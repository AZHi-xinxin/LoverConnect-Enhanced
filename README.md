# LoverConnect Enhanced 2.3

> 让支持 MCP 的 AI 在用户明确授权的前提下，读取有限的手机状态、执行陪伴型操作，并提供可选的自愿安全提醒。

## 项目说明

这是一个基于 [LoverConnect/LoverConnect](https://github.com/LoverConnect/LoverConnect) 继续开发的社区增强版本，并非上游官方发布。

在原有手机状态 MCP 的基础上，本版本重点扩展了以下能力：

- 更完整的手机状态感知：电量、步数、屏幕使用、App 时间线、天气、纪念日和当前播放内容。
- AI 陪伴动作：通知、闹钟、锁屏、音乐应用跳转与本地轻量记忆。
- 有边界的专注辅助：定时应用锁、锁定提示、自动解锁、指定应用跳转和永久保护名单。
- 可选的“小 L”屏幕观察：由用户主动授权截屏，并把分析结果保存在手机本地观察日志中。
- 可选的哨兵事件出口：把有限的结构化事件发送给用户自行部署的接收服务。
- 2.3 自愿安全位置播报：在手机本地判断“家 / 工作”围栏，只上传不含坐标的事件。

所有敏感能力都应由手机用户主动开启。它们用于陪伴、提醒与自我管理，不用于隐蔽监控，也不能替代紧急救援服务。

## 运行方式：只装 APK 还是需要服务端？

LoverConnect 的主要功能只需在手机上安装 APK 即可使用。`server/` 是可选组件，仅在需要远程接收事件、持续执行提醒或进行报备核对时部署；它不一定要运行在 VPS，也可以放在能够持续在线且可被手机安全访问的电脑、NAS 或其他服务器上。

| 功能 | 只装手机 APK | 需要额外服务 |
|---|---:|---:|
| 电量、步数、屏幕使用、App 时间线、天气、纪念日、当前播放 | ✓ | — |
| 通知、闹钟、锁屏、应用锁、专注跳转、本地轻量记忆 | ✓ | — |
| “小 L”截屏观察 | ✓ | 另需用户自行配置兼容的视觉模型 API；不要求使用本仓库服务端 |
| “家 / 工作”安全区的本地设置、判断与粗粒度状态查询 | ✓ | — |
| 安全位置事件远程上传、离家提醒、报备核对与到达回执 | ✓ | 需要运行 `server/` 中的常在线接收服务 |
| 哨兵事件远程出口 | ✓ | 需要用户自行部署并配置可访问的接收端 |
| 同一部手机上的 RikkaHub 等 MCP 客户端连接 | ✓ | — |
| 外出时从其他设备跨网络访问手机 MCP | ✓ | 需要可信私有网络或安全中转；不要直接暴露端口到公网 |

不使用远程安全提醒和哨兵事件出口时，无需准备 VPS，也无需启动 `server/`。

## 安装

1. 从仓库的 **Releases** 页面下载公开构建 APK。
2. 对照 Release 中的 SHA-256 与签名指纹校验文件。
3. 安装并打开 LoverConnect，仅为准备使用的功能授予权限。
4. 启动 MCP 服务，在 AI 客户端中添加 Streamable HTTP 连接。

同一部手机上的 MCP 客户端使用：

```text
http://127.0.0.1:5000/mcp
```

跨设备访问只能放在可信局域网或受控私有网络中。不要把手机的 5000 端口直接暴露到公网。

> 公开 APK 使用独立签名证书。若手机中已有相同包名但签名不同的版本，Android 会拒绝覆盖安装；卸载旧版前请先自行备份需要保留的本地数据。

## 权限按功能分配

| 权限或系统能力 | 用途 | 是否可选 |
|---|---|---|
| 通知 | MCP 常驻服务、提醒与闹钟提示 | 基础运行建议开启 |
| 使用情况访问 | 屏幕时间和 App 时间线 | 可选 |
| 体力活动 | 步数统计 | 可选 |
| 电池优化白名单 / 自启动 | 降低后台服务被系统终止的概率 | 建议开启 |
| 通知使用权 | 获取当前播放信息 | 可选 |
| 无障碍服务 | 应用锁和专注跳转 | 可选 |
| 设备管理员 | `lock_screen` | 可选 |
| 屏幕捕获授权 | “小 L”截屏观察 | 每次由系统界面确认 |
| 精确与后台定位 | 自愿安全位置播报 | 默认关闭，可选 |

不同 Android 厂商的后台管理入口不同；在 OPPO、vivo、小米等设备上，可能还需手动允许后台运行。

## 2.3 自愿安全位置播报

此功能在手机本地维护“家 / 工作”两个安全区域，并把稳定确认后的离开、到达、距离档位或定位降级转换成结构化事件。

核心边界：

- 默认关闭，只能从手机界面授权、设置和开启。
- 原始坐标由 Android Keystore 加密保存在手机本地。
- 坐标不会进入 MCP 返回值、事件正文、服务端数据库或日志。
- AI 只能读取开关、粗粒度区域状态和待发送数量，不能静默设置安全区。
- GPS 丢失、精度不足或单点漂移不会直接判定为离开。
- 离线期间的旧事件会压缩，恢复网络后不会补发已经失效的离开警报。

完整设计、事件类型和报备核对边界见 [`LOCATION-SAFETY.md`](LOCATION-SAFETY.md)。

## 可选服务端

[`server/`](server/) 提供一个无第三方运行时依赖的 Python 接收器，用于承接安全位置与哨兵事件。它包含：

- Bearer Token 鉴权；
- 严格字段校验与坐标字段拒绝；
- SQLite 持久化；
- `event_id` 幂等；
- 请求限流；
- 可恢复任务租约；
- 离开、到达、离线摘要和报备确认流程。

部署说明见 [`server/README.md`](server/README.md)。真实凭据必须保存在仓库外的受限环境文件中，禁止提交到 Git。

## 当前状态与限制

- 当前源码版本：`2.3.0-rc4`，属于候选发布版本。
- 屏幕观察需要用户主动授权，并自行配置兼容的视觉模型服务。
- 音乐工具负责准备搜索并打开应用，不保证绕过第三方音乐 App 的交互限制自动播放。
- 部分厂商系统会限制后台定位或无障碍服务，实际保活效果取决于设备设置。
- 安全位置功能只提供陪伴提醒，不监控连续轨迹，也不构成紧急救援承诺。
