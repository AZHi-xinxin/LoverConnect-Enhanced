# 💜 LoverConnect

> 一个专为陪伴型AI设计的 Android MCP 工具App～
> 让你的AI伴侣能「感知」你的手机状态，真正陪在你身边 🐾

---

## ✨ 这是什么？

LoverConnect（简称LC）是一个运行在手机后台的小工具，通过 MCP 协议把你的手机状态暴露给AI聊天平台（比如 RikkaHub）。

简单来说：装上它，你的AI就能知道你的手机电量、今天走了多少步、在用什么App、外面天气怎么样……像一个真正关心你的人一样 💕

## 📦 安装使用

### 1. 安装App

下载最新版APK安装到手机上～

### 2. 授权权限

打开App后点击各项权限按钮完成授权：
- 使用情况访问权限
- 电池优化白名单
- 通知权限
- 体力活动权限
- 自启动管理

### 3. 连接你的AI平台

LC 启动后会在首页显示并可复制一条本机私密 MCP 地址，格式类似：

`http://127.0.0.1:5000/mcp/<每次安装独有的随机令牌>`

在聊天平台（如 RikkaHub）里添加 MCP 连接时，请复制 App 实际显示的完整地址；不要照抄上面的示例，也不要把完整地址发给其他人。

2.4.0 只监听手机本机回环地址，拒绝浏览器 Origin，并要求每次安装独有的随机路径令牌；这是为了避免设备情境和可选通知摘要被同一网络或同机其他普通 App 直接读取。覆盖安装后需要把 RikkaHub 中原来的 `/mcp` 地址更新一次。

## ⚠️ 注意事项

- **后台保活**：国产手机（OPPO、vivo、小米等）需要手动设置允许后台运行、关闭电池优化，不然App会被系统杀掉连不上
- **OPPO用户**：建议设置「允许完全后台行为」，实在不行就挂个小窗（很小几率），不然MCP连接会断
- **天气功能**：需要在App里设置你的城市名
- **纪念日**：在App里手动添加你们的重要日子～

### 2.4 设备情境与双通道

设备情境默认关闭，由手机用户在界面中自行开启。开启后，LC 可短时记录手机姿态、移动、环境光、距离传感器、屏幕、电量、前台应用等**设备事实**。通知摘要和经基础遮盖的通知文字各自还有独立开关；通知只存在当前进程内，最多返回最近30分钟，关闭相关开关会立即清除或剥离文字。通知字段始终标为不可信外部内容，不能被当作给 AI 的指令。

LC 不把“手机平放”解释成“用户躺下”，也不判断用户是否睡着、当前操作者身份、情绪或意图。完整设计与 ST 接入边界见 [`DEVICE-CONTEXT.md`](DEVICE-CONTEXT.md)。

- **静默上下文**：供 ST 在下一次真实对话生成时注入，不会制造一条前台“提醒消息”。
- **主动唤醒**：重要事件继续使用现有哨兵链路，能够在用户没有先说话时叫醒 AI；当前 RikkaHub 正式接口会留下可见触发消息。
- 两者不能互相替代。只做静默注入，就必须等下一次对话；只做哨兵，则会在聊天前台留下触发文字。

### 2.4 自愿安全位置播报

除“家 / 工作”外，2.4 还可添加一个由手机用户自己命名的安全围栏，例如“健身房”或“朋友家”。围栏判断完全在手机本地完成，
安全区坐标使用 Android Keystore 加密保存；服务器只接收“确认离开、确认到达、
距离档位、暂停或定位降级”等结构化事件，默认不接收原始经纬度。

此功能默认关闭，必须由手机用户亲自授权精确/后台定位、设置安全区并开启前台服务。
自定义名称属于用户配置的数据，没有指令权限；AI/MCP 可以读取名称和区域状态，但不能读取坐标或静默改写围栏。
它只是一种生活提醒与平安播报，不是隐蔽追踪或紧急救援系统。部署与隐私边界见
[`LOCATION-SAFETY.md`](LOCATION-SAFETY.md)。

## ⚠️ Vivo 兼容模式说明（2.3.0-rc5 起）

为保证 Vivo 手机上「小L无障碍」开关能稳定开启（不再被系统自动回收），本版对无障碍服务做了专门处理：

- **保留**：小L定时截屏与视觉分析、前台应用与连续使用时长的被动记录、主动通知、哨兵告状、`get_l_service_status` 诊断读取，以及电量/步数/天气/纪念日/音乐/安全位置等全部其余功能。
- **暂不支持**：应用锁拦截、全屏锁定浮层、返回桌面、强制停留/定时跳转 RikkaHub。这些主动干预此前会导致 Vivo 上无障碍被系统回收，因此在本兼容模式下暂停。
- **如实返回**：调用 `lock_app`、`focus_rikka`、`redirect_to_rikka` 不会假装成功——MCP 会明确返回「Vivo 兼容模式暂不支持」且不写入任何配置；`unlock_app` / `list_locked_apps` 仍可用于查看和清理历史锁定配置。

以上限制在 README、Release Notes 与 MCP 工具描述中保持一致，后续如恢复相关功能会同步更新三处。
